# Amazon FreeRTOS OTA on AmebaD

## OTA update prerequisites
1. Prerequisites for OTA updates using MQTT, please refer to [official amazon ota prerequisite page](https://docs.aws.amazon.com/freertos/latest/userguide/ota-prereqs.html)
2. Create an Amazon S3 bucket to store your update
3. Create an OTA Update service role
4. Create an OTA user policy
5. Create esdsasigner.key and ecdsasigner.crt by openSSL (optional), example:

    ```
    sudo openssl ecparam -name prime256v1 -genkey -out ecdsa-sha256-signer.key.pem
    sudo openssl req -new -x509 -days 3650 -key ecdsa-sha256-signer.key.pem -out ecdsa-sha256-signer.crt.pem
    ```

6. Add certificate pem(ecdsa-sha256-signer.crt.pem) into component\common\application\amazon-freertos\ports\amebaZ2\config_files\ota_demo_config.h

## How is the OTA firmware signature generated:

> [!WARNING]
> !!!!!!! The key pair in SDK are just for example, please generated new key by openssl !!!!!!

1. Before compiling OTA image, update the `"serial"` number to a higher number. To achieve this, navigate to project/realtek_amebaz2_v0_example/GCC-RELEASE/amebaz2_firmware_is.json, update the `"serial"` number of `"FWHS"`
    ```json
    "FWHS": {
        "source":"application_is/Debug/bin/application_is.axf",
        "header":{
            "next":null,
            "__comment_type":"Support Type:PARTAB,BOOT,FWHS_S,FWHS_NS,FWLS,ISP,VOE,WLN,DTCM,ITCM,SRAM,ERAM,XIP,M0,CPFW",
            "type":"FWHS_S", 
            "enc":false,
            "user_key2":"BB0102030405060708090A0B0C0D0E0F101112131415161718191A1B1C1D1E1F",
            "__comment_pkey_idx":"assign by program, no need to configurate",
            "serial": 100 // --> update this to higher number, e.g. 101
        },
    ```

2. We are using custom signing feature provided by amazon to manually sign the OTA binary(firmware_is_pad.bin).
3. The custom signing is being done by means of a python script that we provide in the folder: component/common/application/amazon-freertos/tools/amebaZ2/python_custom_ecdsa_Z2_gcc_NEW.py

    - The python script requires the following pre-requisites to work
        1. Python must be installed in the windows/linux system with version 3.7.x or later
        2. Python cryptography library must be installed using 'pip install cryptography'
        3. The ECDSA signing key and the Certificate pair must be present in the same folder as the python script and must be named 'ecdsa-sha256-signer.key.pem' and 'ecdsa-sha256-signer.crt.pem' respectively.
        4. Once all these are present and the python script is run, it will generate a custom signed binary named firmware_is_pad.bin inside the component/common/application/amazon-freertos/tools/amebaZ2/ folder.
    - Run the python script in folder: component/common/application/amazon-freertos/tools/amebaZ2/
        * shell command after GCC build:

            ```
            python python_custom_ecdsa_Z2_gcc_NEW.py
            ```
    - There might be some error if there are packages lack in your environment (like openssl...). Please install the package and run the script again.

4. After getting the custom signed 'firmware_is_pad.bin' and 'IDT-OTA-Signature', you can upload it to the S3 bucket.

## How to trigger a custom signed OTA job in amazon AWS IOT core.
1. Click on 'Create OTA update job', select your thing/things group and then select next.
2. In the following page, choose the option 'Use my custom signed firmware image'
3. Choose your custom signed firmware binary that was generated by the python script from S3 bucket.
4. In the signature field please enter the content of 'IDT-OTA-Signature'
5. Choose hash algorithm as 'SHA-256'
6. Choose encryption algorithm as 'ECDSA'.
7. In "pathname of code signing certificate" and the "Pathname of file on device", both enter '/'
8. Choose the IAM role for OTA update job.(This is the same IAM role as any OTA update job)
9. Click next, give a unique name for the job and create.
